Additional design reference: Espanso's clipboard backend preserves/restores the clipboard independently of editor introspection. No Espanso code is included.
https://github.com/espanso/espanso/blob/0cadaeaddf9aeb6d128668ea5db354b7c635ec20/espanso/src/cli/worker/engine/dispatch/executor/clipboard_injector.rs

The Swift implementation preserves every clipboard representation. Clipboard reads and event posting are not proof of insertion; exact field/caret read-back is required for verified success. Opt-in Auto-send can also follow settled clipboard consumption with unchanged focus; it reports Return posting, not confirmed insertion or message delivery.
